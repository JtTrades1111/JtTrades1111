# Sample data

Fictional data (summer 2026) so you can click through the dashboard immediately.

| File | What it is | How to load |
|------|-----------|-------------|
| `discover.csv` | Discover credit-card export (36 rows) | **Import CSV** button — auto-detected as a liability |
| `usaa.csv` | USAA checking export (36 rows) | **Import CSV** button — auto-detected as an asset |
| `sample-data.json` | Both CSVs already imported + two manual investments, target = $12,000 by Sep 1 | **Import data** button — loads the whole dashboard at once |

Fastest path: click **Import data** in the top bar and pick `sample-data.json`.

To exercise the importer instead, click **Import CSV** and load the two CSVs
one at a time (re-import either one to see the duplicate-skip toast).

All names, merchants, and amounts are made up.
